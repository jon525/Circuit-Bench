# Circuit Bench

An electrical and physics formula workbench in a single HTML file. Open `index.html` in a browser; no build step or install needed.

## Tools

- **Universal solver**: enter any known values (voltage, current, resistance, power, energy, time, charge, efficiency, force, mass, acceleration, work, distance) in any units. It chains 30 formulas to find everything else, shows the working step by step and flags values that contradict each other.
- **Ohm's wheel**: all 12 rearrangements of V = I × R and P = V × I, each with its own calculator.
- **Resistors**: series and parallel combinations, nearest E24 value, and a 4-band colour code reader.
- **Capacitors & RC**: series and parallel combinations, time constant, stored charge and energy, with a charging curve.
- **Cable drop**: voltage drop for copper or aluminium conductors, single- or three-phase, with the smallest size that meets your limit. Simplified (resistance only, 20 °C); use AS/NZS 3008.1.1 for installation design.
- **Running cost**: appliance energy use and cost per day, quarter and year at your c/kWh rate.
- **Units**: SI prefix converter, prefix table and symbol glossary.
